# 小程序真机清单

> 给维护者。H5 检查和组件逻辑测试量不出来的，要在微信开发者工具和真手机上看一眼。按顺序勾，一遍大约 30 分钟。
> 对应 `MINI-REVIEW-PLAN.md` 里标「待真机」的条目。看到不对的，记下机型、微信版本、哪一步，发给 AI 助手改。

## 准备

- [ ] 装微信开发者工具，设置 → 安全 → 打开「服务端口」。
- [ ] `pnpm --filter @xxd/mini-demo build:weapp`，用开发者工具打开 `packages/xxd-mini-demo/dist`（AppID 用测试号）。
- [ ] 先跑一遍自动检查：`pnpm dlx -p miniprogram-automator node packages/xxd-mini-demo/scripts/check-devtools.mjs`。
  它会截图到 `packages/xxd-mini-demo/shots/devtools/`，并报出左滑一次的 `setData` 次数。
- [ ] 开发者工具里「预览」，用一台 iPhone 和一台安卓（最好是中低端机）扫码。

## 1. 标签栏和底部（Q4）

- [ ] 底部的标签栏是我们的样子（墨色选中、细线），不是微信缺省的。
- [ ] 「组件 / 待办 / 外观」来回切：不闪白、不重新加载；在待办里滚到一半，切走再切回来，还在原来的位置。
- [ ] 外观里切成暗色、换主色：标签栏马上跟着变。
- [ ] 待办页：底部按钮条「新建」在标签栏上面；加到 20 件，滚到底，最后一行完整露出来。
- [ ] 删除一件：「已删除 · 撤销」的轻提示浮在「新建」上面，不盖住它。

## 2. 键盘（I5）

- [ ] 待办 → 新建：键盘弹出后，面板整个升到键盘上面，「添加」按钮看得见、点得到（iPhone、安卓各一次）。
- [ ] 中文输入法打「下午五点交周报」：拼音过程中不丢字、光标不跳到最后（S4）。
- [ ] 粘贴一段超过 60 字的文字：多出来的被截掉，并有提示。

## 3. 返回键和浮层（S2、I2）

- [ ] 组件 → 对话框 → 「删除这篇」：按手机返回键（安卓）/ 从左边缘右滑（iPhone），先关对话框，还在这一页；再按一次才回上一页。
- [ ] 组件 → 底部面板：按住顶上的把手往下拖，拖一点松手弹回去，拖过一半松手关掉；快速往下一甩也能关。
- [ ] 面板打开时，下面的页面不跟着滚。

## 4. 手感（S1、I3、I10）

- [ ] 待办里左滑一行：跟手，不卡顿（中低端安卓机重点看）。滑开一行后再滑另一行，前一行收回。
- [ ] 长按一行待办：轻震一下，弹出「更多操作」。
- [ ] 外观页：点「圆角」这一整行（不是只点开关）就能切换。

## 5. 首帧和外观（S5、S6）

- [ ] 手机是亮色，外观里选「暗」：每进一个新页面，导航栏直接是暗的，不先闪一下亮色。下拉页面露出的底色也是暗的。
- [ ] 自定义导航栏（组件 → 导航栏）：标题居中，和右上角的胶囊上下对齐；横屏、iPad、电脑版微信上不变形。

## 6. 读屏（S11）

- [ ] iPhone 打开旁白（设置 → 辅助功能 → 旁白），走一遍待办：新建、勾选、删除（每行有「更多操作」）。
- [ ] 打开对话框时，旁白读不到后面的页面。
- [ ] 安卓打开 TalkBack，同样走一遍。

## 7. 其他

- [ ] 微信 → 我 → 设置 → 通用 → 字体大小，调到最大：页面不挤坏、文字不被裁。
- [ ] 详情 → 本地设置里把渲染引擎切到 Skyline 跑一遍（MINIPROGRAM-PLAN §16）：网格退成一列可以接受，别的不该坏。
- [ ] 输入框所在的页面打开对话框：输入框里的字不会浮在对话框上面（S10）。
- [ ] 量表（组件 → 量表，GAUGE-PLAN G5）：表盘图片清楚不发虚、细线（刻度、目标线、指针）是 1px 左右；切暗色、圆角后颜色和线头跟着变；
      点「喝了几杯」的加减，表盘重画时不闪白；旁白把表盘读成一句（「本月额度，94%，超限，目标 80%」）。
- [ ] 图型（组件 → 条形榜 / 构成条 / 百格图 / 热力格 / 前后对比，CHART-TYPES-PLAN H5）：百格的格子是正方形（`aspect-ratio`，老的安卓 WebView 可能不认）；
      热力格的日历一打开就停在最右边（最近一周），横着滑顺；140 个格子的页面进出不卡；条形榜和前后对比旁白一行一行念。
- [ ] 图型对抗测试（CHART-REVIEW-PLAN）：热力格点一格，色阶那一行左边写出这一格（日期和数），这一格有墨色细框；
      日历仍然一打开就停在最右边（小程序用 scroll-left，不用网页版的 direction 办法）；条形榜、前后对比的名字在条上面一行，数字那一栏对齐，旁注在数字那一栏里换行。
