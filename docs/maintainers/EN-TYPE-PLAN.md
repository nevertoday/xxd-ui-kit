# 英文页的字（标题的声音和标签）

> 2026-11-13。接着 FEEDBACK-ALIGN-PLAN 的 D182 编号（D183 起）。前三条维护者定，其余 AI 定，维护者可以改。做完在第 4 节打勾写日期。
> 起因：维护者看了 browserr.dev，想让英文版有它那种排版的逻辑：大标题和导语是衬线，像出版物；一行的小标签是等宽大写、拉开字距，像仪表上的刻字；正文不动。

---

## 0. 结论

- **只动英文页，只动两个用途**：整屏的标题（加导语）和一行的小标签。正文、控件、中文页都不动。
- **在令牌层做**：`tokens.css` 多了一组用途令牌，中文页的值就是现在的样子，英文页（`lang="en"`）在一个块里换值。
  组件、展示站、插件（Shadow DOM）、React（Kumo 绑定层）都只写用途令牌，不判断语言，自己跟着变。
- **维护者定的三条**：英文标题用**系统**衬线，不加载网络字体；等宽大写**只给标签**，按钮、tab、chip、徽标、菜单照原样；放在令牌层，页面或元素是英文就跟着变。

## 1. 参考了什么、没拿什么

browserr.dev 的样式（只看思路，不搬代码）：

| 它的做法 | 拿了吗 |
|---|---|
| 节标题（h2）衬线 500、-0.01em；导语（dek）衬线 | 拿了：整屏的标题都用系统衬线 500、-0.01em，导语用衬线 400 |
| 小标签（表头、分组名、kicker）等宽、大写、拉开字距（0.06em–0.18em，好几种） | 拿了：只有一种字距 0.08em，只给标签 |
| 等宽的大标题（H1 700、-0.04em） | 没拿：标题是衬线，等宽只在标签和代码里 |
| 标签、按钮 700 | 没拿：字重只有 400 / 500 / 600，标签照旧 500，衬线标题 500 |
| 按钮、chip、tab 也是等宽大写 | 没拿：控件永远照原样大小写 |
| 网络字体 | 没拿：只用系统里的字体 |
| 标签用很浅的灰（`--ink-4` #999，白底 2.8:1） | 没拿：标签照旧 `--muted`，对比度 ≥ 4.5 |

## 2. 用途表

| 令牌 | 中文页（缺省） | 英文页 |
|---|---|---|
| `--font-title` | `var(--font-body)` | `"Iowan Old Style", "Palatino Linotype", Palatino, "Book Antiqua", Georgia, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", serif` |
| `--weight-title` | `var(--weight-strong)`（600） | `var(--weight-medium)`（500） |
| `--tracking-title` | `normal` | `-0.01em` |
| `--font-label` | `var(--font-body)` | `var(--font-mono)` |
| `--text-label` | `var(--text-xs)`（12） | `var(--text-2xs)`（11） |
| `--case-label` | `none` | `uppercase` |
| `--tracking-label` | `normal` | `0.08em` |

谁用：

- **标题**（字体、字重、字距）：`.xxd-text` 的 display / heading1 / heading2、`.xxd-title`、`.xxd-page-header__title`、`.xxd-prose` 的 h1 h2、展示站的 `.site-h2`；
  导语 `.site-lead` 只换字体（400 不变）；Kumo 的 `Text` heading1 / heading2 / heading `size="lg"`（20px 以上）。
- **标签**（字体、字号、字距、大小写，行高 `--leading-xs` 16）：`.xxd-table thead th`（排序按钮 `font: inherit` 跟着变）、Kumo 表格的表头；
  展示站的侧栏分组名、目录标题、外观浮层的分组名、属性表的表头、对照页的列头。
- **不用**：heading3 和块里的标题（卡片、面板、对话框）、统计和量表的数字、所有控件、正文、说明。

## 3. 决定

- **D183 英文标题用系统衬线**（维护者定）：Iowan Old Style（macOS / iOS）→ Palatino Linotype / Book Antiqua（Windows）→ Georgia（都有）→ `serif`。
  中文黑体排在 `serif` 前面：英文页里夹的中文（语言名、中文示例）落到苹方 / 雅黑，不落到宋体。不加载网络字体。
- **D184 导语和标题同一个声音**：`.site-lead` 用 `--font-title`，字重照旧 400。导语是一段话，不是标签，不大写。
- **D185 衬线标题 500**：系统衬线没有半粗，600 会拿到 Bold（太黑，像海报），500 落在常规体上，靠字号分层级。
  `--weight-title` 只能指向 400 / 500 / 600 里的一档（测试查）。
- **D186 标题字距 -0.01em**：衬线大字的字面宽，收一点才紧。中文页 `normal`，中文不改字距。正文任何语言都不改。
- **D187 标签等宽**（维护者定只给标签）：`--font-label` 是 `--font-mono`。只给「一行、给一组东西起名字」的字：表头、侧栏分组名、目录标题。
- **D188 标签大写、字距 0.08em**：大写字母挤在一起难认，拉开一点。只有一种字距，不像参考那样每处不同。
- **D189 标签 11 / 16**：等宽比周围小一档（D69）；11px 只给不会出现中文的字（D71），英文页的标签就是。只一行（D162 的表），放不下按 TRUNCATION 的规则在末尾省略。
- **D190 标题的范围**：只给「整屏的标题」（D67 那一档）：页面标题、节标题、阅读里的 h1 h2。块里的标题、对话框标题、统计数字不换——它们在控件旁边，换成衬线会和控件不像一家。
- **D191 控件永远不大写**（维护者定）：按钮、tab、chip、徽标、菜单、分段、下拉的字照原样。大写的按钮在英文里读着像喊，而且和中文页的同一个按钮宽度差太多。
- **D192 跟着语言走，整页或一块**：`:root:lang(en), [lang]:lang(en)` 换成英文的值；英文页里写了别的语言的一块（`:root [lang]:not(:lang(en))`）换回中文的值。
  Shadow DOM 里构建成 `:host(:lang(en))`，宿主页面是英文，插件里的组件也跟着变。中文页的根上不多出任何规则。
- **D193 Kumo 在绑定层跟**（`kumo-binding.css`，不动组件源码和生成文件）：`Text` 20px 以上的标题、表格的表头写用途令牌；`--font-serif` 指向 `--font-title`（注释改掉「小小东不用衬线」）。
  对照门禁（`parity.mjs`）的表头多比三项：第一个字体名、字距、大小写。
- **D194 中文页一个字都不变**：中文页（不在 `/en/` 下的每一页，React 演示也打开）每个元素的字体、字重、字号、行高、字距、大小写、尺寸改前改后逐个比，必须完全一样。

## 5. 没改的

- **contrast、dark、focus 门禁只走中文页**：这次手动换成英文页跑过一遍，门禁本身没改。
- **小程序**（`@xxd/mini`）：令牌是算好的值，不认 `:lang()`，英文版还是现在的样子。
- **中文页的「字体与层级」页**：说明文字没改（中文页照旧）；英文页的说明、层级表、行高表写了英文页的新规则。
