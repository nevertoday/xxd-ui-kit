# 图表（ECharts）对抗测试

> 2026-10-23。接着 TOUCH-REVIEW-PLAN 编号（D123 起），AI 先定，维护者可以改。做完在第 4 节打勾写日期。
> 六种 CSS 画的图（条形榜、构成条、百格图、热力格、前后对比、量表）在 CHART-REVIEW-PLAN 里测过，这一轮是另一半：
> `Xxd.chartOptions()` 套在 ECharts 上的图，和 @xxd/react 里从 Kumo 来的 `Chart`、`TimeseriesChart`、`SankeyChart`、地图、`ChartLegend`。

---

## 0. 结论

- **换算之外的地方都比较薄**：`chartOptions` 只按折线、柱子、散点三种写过，别的图种、高对比、读屏、窄屏都没想过。
- **会误导、会看不见的**：
  1. **饼图每一块都是同一个颜色**（主色），分不出哪块是哪块；饼后面还多画了一副空坐标轴，提示也不出来。
  2. **高对比模式（暗底）下主线和柱子看不见**：墨色 #111 画在黑底上；网格线反而最亮。
  3. **柱状图的类目名被自动藏掉一半**（窄的时候「排序链接」「今日待办」不显示，那两根柱子不知道是谁）。
  4. **读屏念的是乱的**：「第0个系列」「1日的数据是0，42」（把序号当成了数）、时间念成 13 位毫秒数、缺的值念「NaN」；英文是「It consists of 2 series count」。
  5. **图例只靠颜色**：第二条线是虚线，图例里却是一样的短横（WCAG 1.4.1，规则里说过线型也区分）。
- **难用的**：图例换行压住图；刻度数太长（「6,000,000,000」占掉三分之一宽）；参考线的数被裁掉（19.5 显示成「19」）；横向条形图的顺序倒过来；
  每张图都有进场动画（§14 说不做），减少动效时也照样动；手机上点出的提示不走；打印时图不跟着纸宽缩；中文刻度 11px（规则是不小于 12px）。
- **Kumo 来的图表还是 Cloudflare 的样子**：蓝、黄、粉三色，虚线网格，和小小东的配色没有关系。

## 1. 怎么测的

- 一页极端数据：两条线、7 条长名字的线、十亿级的柱、正负柱、饼图、散点、空数据、坏值（null、"-"、NaN、Infinity、字符串）、面积、参考线、
  横向条形（长类目名）、双 y 轴、带标签注入的名字、时间轴、堆叠柱。每张都用 `Xxd.chartOptions(option, { el })` 画、`watchChartTheme` 看着。
- Playwright：800 / 375 / 320 宽、iPhone 13（触屏）、暗色、高对比（`forced-colors: active` + 暗）、减少动效、打印（`beforeprint` 后读 canvas 像素）。
  每张截图逐张看；用 ECharts 的 API 读出最终选项（有没有坐标轴、提示怎么触发、每一块的颜色、动画开没开）。
- 提示：每张图在最后一个数据点上 `showTip`，读提示的文字（有没有转义、数字怎么写），量会不会伸出屏幕。
- 触屏：在图上划过页面（页面能不能滚）、点图、点图外面（提示走不走）。
- 读屏：读每张图容器上的 `aria-label`，中英两版。
- Kumo 的 `TimeseriesChart`、`SankeyChart`、`ChartLegend`：用 @xxd/react 打一个小包，放在展示站的样式下截图。

## 2. 发现

严重度：**P0** 会误导 / 看不见；**P1** 难用；**P2** 打磨。

| # | 发现 | 严重度 |
|---|---|---|
| E1 | 饼图（按数据上色的图：饼、漏斗、旭日、矩形树图）每一块都是主色：`chartOptions` 给每个系列写了 `color` | P0 |
| E2 | 饼图后面多一副空坐标轴（总是加 `xAxis` / `yAxis`）；提示固定 `trigger: "axis"`，饼图没有提示，散点的提示是「3.00 4」 | P1 |
| E3 | 高对比模式：线和柱是令牌里的墨色，暗底上看不见；网格线是浅灰，比数据还显眼 | P0 |
| E4 | 柱状图类目轴的名字按 ECharts 的「放不下就隔一个藏一个」，名字没了柱子还在 | P0 |
| E5 | 读屏描述是 ECharts 自动拼的：序号从 0 数、把类目序号当数据、时间念毫秒数、坏值念 NaN、大数没有千分位；英文语法不通 | P1 |
| E6 | 图例图标是 10×2 的方块：看不出线型，虚线和实线在图例里一样（只靠颜色） | P1 |
| E7 | 图例换行时压住图（图区上边固定留 40px）；320 宽两条长名字、800 宽 7 条都压住了刻度 | P1 |
| E8 | 刻度数不缩写：十亿级的数占掉三分之一宽（六种 CSS 图已经按 D52 缩写） | P1 |
| E9 | 参考线的数在线的右端、图区外面，被裁掉：19.5 显示成「19」（截断的数字是错的数字） | P1 |
| E10 | 横向条形图（类目在 y 轴）第一项画在最下面，顺序和作者给的、和网页的条形榜都相反 | P1 |
| E11 | 每张图都有进场动画（线从左往右长、柱子从 0 长），设计原则 §14 说不做进场动画；减少动效时也照样动 | P1 |
| E12 | 手机上点过图，提示一直留着；点图外面、滚动页面都不走 | P2 |
| E13 | 打印：canvas 是按屏幕宽度画的，纸比屏幕窄时右边被裁掉（打印时不会触发重排） | P2 |
| E14 | 中文刻度、参考线的字 11px（TYPE-REVIEW 定的是中文不小于 12px） | P2 |
| E15 | 第 6 条起颜色、线型和第 1 条一样，看起来也是重点线 | P2 |
| E16 | `watchChartTheme`：根元素上任何 `style` 变化都整张重画；图销毁了还在看；不管尺寸（作者要自己写 ResizeObserver） | P2 |
| E17 | 组件页的规则还写着「墨色按 78% / 64% / 54% / 46% 往纸色混」，D51 以后已经不是这样 | P2 |
| K1 | Kumo 的 `TimeseriesChart` / `SankeyChart` / 地图 / `ChartLegend` 用 Cloudflare 的蓝黄粉、虚线网格；`<Chart>` 不传颜色时也是这一套 | P1 |

没出问题的：提示里的名字都转义了（注入的标签原样显示成字）；坏值不会让图出错；320 宽提示不会撑出横向滚动；切主题不会重放动画；
`beforeprint` 换亮色后 canvas 在打印前就重画好了；在图上竖着划，页面照常滚。

## 3. 决定

- **D123 按图种套主题**：
  - 只有折线、柱子、散点这种「一个系列一个颜色」的图写系列色；饼、漏斗、旭日、矩形树图、桑基这种按数据上色的不写，每一块按分类色的顺序取。饼的每块之间留 1px 纸色的缝。
  - 坐标轴和图区只在有直角坐标系的系列（或者作者自己写了）时才加。
  - 提示：有折线、柱子时按坐标轴（`axis`），否则按单个数据（`item`）。
- **D124 高对比模式**：颜色换成系统色（线、柱、字是 CanvasText，网格线是 GrayText，底是 Canvas），每一类靠线型和花纹分（柱子、饼打开 ECharts 的 `aria.decal` 花纹）。
  进出高对比模式时重画。
- **D125 类目全写出来**：柱状图的类目轴每一个名字都写，放不下就在自己那一格里折行。知道图有多宽（传了 `el`）时才能算格宽；不知道时照 ECharts 的。
  横向条形图（类目在 y 轴）从上往下是作者给的顺序。
- **D126 读屏描述自己写**：按页面语言（简体、繁体、英文）写一句话：什么图、几条、叫什么、横轴从哪到哪、每条从多少到多少、最低最高；饼图写每块的数和占比。
  数字按语言加千分位，缺的值跳过，时间写成日期。作者写了 `aria.label.description` 时用作者的。
- **D127 图例**：折线的图例画出线型（实线、虚线、点线，24px 长，没有圆点）；柱子是 10×10 的方块。
  图例换行时图区往下让，让出几行就让几行（按图的宽度量图例的字宽；不知道宽度时按手机的 360px 算）。
- **D128 刻度数缩写**：和 D52 一样：写全了超过 5 个字符就缩写（「60亿」「6B」）。提示和读屏里是全数。作者写了 `axisLabel.formatter` 时不动。
- **D129 参考线**：字放在线的上方、图区里面的右端，写「名字 数」，永远不被裁。
- **D130 动效**：缺省不放进场动画（§14）；作者要动画写 `animation: true`；减少动效时一律不放，切换时重画。
- **D131 第 6 条起是背景线**：`--muted-2`、1px 实线、不参与高亮，控制台提醒一次「超过 5 条，拆图或只高亮一条」（组件页规则里本来就这么写）。
- **D132 `watchChartTheme` 管全**：
  - 令牌真的变了才重画；
  - 也看尺寸：图的大小变了就 `resize()`，和宽度有关的选项（图例让行、类目折行）重算；
  - 看高对比、减少动效；
  - 触屏上点图外面、滚动页面时收起提示；
  - 图销毁后自己解绑。
  组件页的示例不用再自己写 ResizeObserver。
- **D133 打印**：图的 canvas 在打印时最宽是纸宽，等比缩小。
- **D134 字号**：刻度、参考线、图例的字 12px。
- **D135 Kumo 的图表接上令牌**：页面上有小小东的令牌时（根元素上读得到 `--action`），`ChartPalette` 的分类色、语义色、字色、地图色都从令牌取，
  `<Chart>` 缺省的系列色也是；`TimeseriesChart` 的网格线是发丝实线。没有令牌（单独用 Kumo）时照旧。
- **D136 门禁**：audit 加 `--only=chart`：在组件页里画一组极端图，检查饼图每块颜色不同、没有空坐标轴、高对比下每个系列和底色 ≥ 3:1、
  减少动效时没有动画、读屏描述里没有 NaN / 毫秒数 / 「第0个」、柱状图类目一个不少、图例和图区不重叠、参考线的字在图里。

## 5. 没改的

- **键盘读不到 canvas 里的每个点**：ECharts 没有键盘导航。靠读屏的一句话和图旁边的结论 / 表（组件页规则里本来就要求）。
- **Kumo `TimeseriesChart` 的读屏描述**还是 ECharts 自动拼的（会念毫秒数）：它有 `ariaDescription` 参数，作者传一句话；Kumo 没有三语的文案表，不在这里加。
- **Kumo 图表切主题不会自己重画**：颜色在渲染时读令牌，`isDarkMode` 变了才重画；用 @xxd/react 时把 `isDarkMode` 接到外观设置上。Kumo 框选（brush）的颜色还是蓝灰。
- **React 里 `chartOptions` 拿不到图的 DOM**（Kumo 的 `<Chart>` 里面才 init）：图例按 360px 估行数、类目照 ECharts 的，局部主题看不到。要做得给 `<Chart>` 加一个回调，先不做。
- **饼图超过 5 块颜色会重复**：ECharts 的数据是作者给的，不替作者合并「其他」；§14 说一个整体分几部分用构成条（构成条会合并），不用饼图。
- **7 条长名字的图例在 320 宽占掉大半张图**：照实让行；超过 5 条本来就该拆（控制台提醒）。
- **高对比模式下网格线和第 6 条起的背景线都是 GrayText**，分不开；背景线本来就只是背景。
