# 截断和长文字（对抗测试）

> 2026-10-22。接着 MOTION-REVIEW-PLAN 编号（D91 起），AI 先定，维护者可以改。做完在第 4 节打勾写日期。
> 上一轮验收核查（`ACCEPTANCE-REVIEW.md`）里 visual 报的「截断以后看不到全文」「按钮里的长字被两边硬裁」在这一轮做。

## 0. 结论

- **长文字不会把页面撑坏**：
  - 已有的 `--only=long` 门禁管「不伸出容器、不被挤成一字一行」，这两条守住了；
  - 正文里的长链接、长英文单词都能断开；表格、代码横向滚动。
- **坏在「放不下的时候怎么办」**：
  1. **按钮这类东西里的裸文字被两边硬裁，没有省略号**（「Delete …」显示成「elete "Long-form publis」）。
     弹性布局里的裸文字画不出省略号，居中又把开头推出去了。
  2. **省略号之后看不到全文**：组件里 22 类省略号，一处 title 都没有。
  3. **不该截的被截了**：
     - 英文版 320 宽、用原文就截：dock 状态（「30 characters · Saved」只露一半）、列表标题、卡片标题、图例名、输入组后缀、顶栏标题；
     - 统计值在大数字时出省略号，截断的数字是错的数字。
  4. **React（Kumo）长文字直接伸出容器**：按钮 57–77px、徽标 425px、下拉触发器 71px、面包屑 143px、对话框触发器 67px。

    - 看得见的部分有没有压到别的字（逐行比，折行的行内字不按外框算）。
- **真实页面**：组件、模式、模板、工具页（中英），320 / 390 宽，原文和重复三遍。

## 3. 决定

- **D91 两类字：内容折行，标签才省略**：
  - **内容永不截断，放不下就折行**：
    - 标题：卡片、面板、列表行的标题（对话框、sheet 已经折行）；
    - 状态：dock 状态、toast、出错、帮助（后三个已经折行）；
    - 数字：统计值、价格；
    - 图表的类别名：条形榜、构成条、图例、前后对比、量表标签和状态。
  - **标签一行，放不下才省略**：按钮、chip、徽标、tab、分段、面包屑、侧栏项、顶栏标题、下拉的当前值、输入组前后缀、账号名、列表的次要信息、代码块文件名。
- **D92 省略只在末尾、只用省略号**：不两边裁，不从字中间切。
  - HTML：放不下时 xxd.js 给它标 `data-truncated`，换成画得出省略号的排法（宽高不变）；
  - 没有 xxd.js 时退一步：从开头显示（`justify-content: safe center`），只裁末尾。
- **D93 被省略的都能看到全文**：悬停或键盘聚焦时出提示，就是 `data-tooltip` 那个提示。
  - 读屏本来念的就是全文，所以这个提示不再连 `aria-describedby`，不念两遍；
  - 作者自己写了 `title` / `data-tooltip` 的不动。
- **D94 数字永不截断**：
  - 地方小的大数先缩写（图表已经有）；
  - 统计值放不下时单位换到下一行，数本身不拆；实在比格子还宽才断开，不藏掉。
- **D95 React 不伸出容器**：按钮、徽标、下拉触发器、面包屑链接在绑定层可以收缩，字出省略号，和 HTML 一样。
- **D96 门禁**：audit 的「长内容」一项加四条检查：
  - 不许硬裁；
  - 省略号悬停后能看到全文；
  - 内容和数字不被截；
  - 看得见的字不互相压。
  - 文字变体加上「重复三遍」「长英文」「大数字」，英文示例也跑。

## 5. 没改的

- **触屏看不到全文**：手机上没有悬停，点一下就是点了按钮。被省略的标签在手机上只能靠读屏或换个地方看（比如详情页标题）。要做的话得是「长按显示」，和系统的长按菜单冲突，先不做。
- **React 没有全文提示**：React 版不跑 xxd.js，省略号以后悬停看不到全文；要在 Kumo 按钮、徽标里各加一个按需的 title，下一轮跟 React 的 tooltip 一起做。
- **React 按钮里放图标的那种**（图标写在 children 里，不是 `icon` 属性）：字和图标在同一个 `display: contents` 里，没法单独省略，放不下时只从开头显示、裁末尾。
- **文件名、路径的中间省略**（`long-file-na…me.pdf`）：CSS 做不到，要 JS 拆字；目前文件名在代码块头里折行。
- **前后对比的数值、展示站的侧栏演示**：只有字变成三倍长时才撑出去，真实内容没遇到，记下不改。
