# 圆角和线（检测与修改）

> 2026-10-22。用户反馈两件事：
> 1. 说好直角，却有圆的，比如头像；
> 2. 边框（包括边框的颜色）没有章法。
>
> 接着 SPACING-REVIEW-PLAN 编号（D61 起），AI 先定，维护者可以改。做完在第 4 节打勾写日期。

---

## 0. 结论

**两条反馈都对，而且问题都出在规则上，不是哪个组件写错了。**

1. **圆**：设计原则 §3 写着「语义上的圆永远是圆：状态点、色块、头像……不跟开关走」。
   于是直角模式下，头像、色块、状态点、徽标的点、前后对比图的两个端点、展示站顶栏的主色点都是圆的。
   规则本身太宽：「语义上的圆」被当成了「小的、可爱的就画圆」。
2. **线**：边框的颜色按「看起来深一点浅一点」挑，不按用途挑。
   - 同一类东西用不同的线：
     - 次要按钮的边是 `--line-strong`（和纸 1.65:1），旁边输入框的边是 `--line-control`（3.63:1）。
       一排里一个浅一个深（首页「插件」那一块的搜索框和「导入」按钮）。
     - 数据表表头下面是灰线，正文里的表头下面是强调色的线。
   - 同一种状态用了六种颜色：
     - 「选中 / 按下」的边：卡片 `--action`，chip 和按下的按钮 `--accent-border`，
       小程序的标签 `--action-text`，复选的半选 `--action-fill`，开关 `--switch-on`。
     - 聚焦：`--accent-border-strong`。
   - 出错的边用文字色 `--danger`，危险描边按钮用 `--danger-border`，横幅用 `--danger-line`：一个颜色家族三个名字三种深浅，看不出规则。
   - 「环」的尺寸各写各的：
     - 头像会员环：隔 1.5 + 环 1.5；
     - 色块选中：隔 2 + 环 1.5；
     - 卡片角标的点：隔 1.5，颜色写死成 `#ffffff`（暗色下变成白圈）；
     - 色块的边：写死成 12% 的黑。

## 1. 怎么测的

- **圆**：展示站 148 个中文页在直角模式下渲染，逐个元素读计算样式。圆角不为 0、而且画得出来（有底、有边、有阴影）的都列出来；
  另外列出 SVG 里的 `<circle>` 和带 `rx` 的矩形。去掉规格表里故意按圆角渲染的样品和「圆角」页的对照。
  静态再扫一遍网页、小程序、展示站的 CSS，找 `--r-circle`、`50%`、`999px`。
- **线**：
  - 静态：把网页和小程序样式里所有 border / outline / 画成线的 box-shadow 按颜色、宽度、选择器列出来。
  - 浏览器：148 页逐个元素读计算出来的边框颜色和宽度，反查是哪个令牌，按组件归类。
  - 线的颜色和纸的对比度算一遍（亮、暗）。

## 2. 发现

### A. 直角模式下的圆（P0）

| 东西 | 现在 | 该不该圆 |
|---|---|---|
| 头像 `.xxd-avatar` | `--r-circle` | 不该：头像是一张图，方的也是头像 |
| 色块 `.xxd-swatch`（主色选择） | `--r-circle` | 不该 |
| 状态点 `.xxd-dot`、徽标的点 | `--r-circle` | 不该：方点一样认得出是「点」 |
| 前后对比图的两个端点 | `--r-circle` | 不该：图里的记号跟着整套走（柱子本来就是直角） |
| 叠在一起的头像 `.xxd-thumbs` | 跟头像 | 不该 |
| 展示站顶栏的主色点 | `--r-circle` | 不该 |
| 小程序：骨架屏的圆块、竖排步骤的序号圈 | `--r-circle` | 不该 |
| **单选 `.xxd-radio`** | `--r-circle` | **该**：单选和复选只靠形状区分（圆 = 选一个，方 = 选几个），画方了就和复选一样 |
| **转圈**（加载、按钮里的进行中） | `--r-circle` | **该**：画的就是绕圈 |
| **量表、庆祝的圆环、图标里的圆** | SVG | **该**：圆弧就是数据或者图形本身 |

### B. 线

- **B1 按钮和输入框的边不一样深**（P0）：次要、描边按钮 `--line-strong`（1.65:1），输入框、下拉、选择器、复选、单选、开关 `--line-control`（3.63:1）。
  REVIEW-PLAN D11 当时只给「能打字、能勾的」加了深边，按钮留着浅边；结果同一行一深一浅。
- **B2「当前」的边六种颜色**（P0）：
  - 选中的卡片、当前目录项 `--action`；
  - 按下的按钮、chip `--accent-border`；
  - 聚焦的输入框、展开的选择器 `--accent-border-strong`；
  - 半选的复选 `--action-fill`，小程序按下的标签 `--action-text`，开的开关 `--switch-on`。
  - 墨色主题下这些大多都是灰，但深浅各不同；换成彩色主题以后差别更明显。
- **B3 有颜色的线三个名字**（P1）：`--{tone}-line`（6 级）、`--{tone}-border`（7 级）、`--{tone}-border-strong`（8 级），
  加上文字色 `--danger`。出错的输入框用 `--danger`，危险描边按钮用 `--danger-border`（1.68:1，比旁边的灰边还浅），横幅用 `--danger-line`。
- **B4 结构线不一致**（P1）：数据表表头下 `--line-strong`，正文表格表头下 `--accent-border`（彩色主题下是彩色）。
- **B5 环的尺寸和颜色各写各的**（P1）：见第 0 节。另外 `#ffffff`、`rgba(17, 17, 17, 0.12)` 是写死的值。
- **B6 悬停加深的规则不一**（P2）：输入框 `--line-control` → `--line-control-hover`；描边按钮 `--line-strong` → `--line-control-hover`（一下跳两档）；
  可点的卡片 `--line` → `--line-strong`。
- **B7 宽度其实只有三种，但没写下来**（P2）：1px（几乎所有线）、1.5px（转圈、图上的点、热力格当前、隔开的环）、2px（焦点轮廓、引用竖线）。

### C. 门禁

- 测试只查「圆角写令牌」，`--r-circle` 谁都能用。
- 边框颜色写什么都行。
- 没有一项检查会因为「直角模式下出现了圆」或「同一行控件边框不一样」而失败。

## 3. 决定

- **D61 只有「形状就是意思」的才永远是圆**：单选、转圈、圆弧和图标里画的圆。
  - 头像、色块、状态点、徽标的点、图上的点、叠放的头像、骨架屏的圆块、步骤序号都跟开关走：写 `--r-pill`。
    直角时是方的，圆角时是圆的（正方形加 999px 圆角就是圆）。
  - `--r-circle` 只给单选和转圈用（门禁守着名单）。设计原则 §3 那一条改写。
- **D62 线的颜色只看用途，四种 + 状态**：

  | 用途 | 令牌 | 用在哪 |
  |---|---|---|
  | 分隔、容器 | `--line`（浮层里自动是 `--line-raised`） | 列表行之间、tab 基线、卡片、分组、横幅、浮层的边 |
  | 结构线 | `--line-strong` | 表头下面、合计上面、键帽、拖放区的虚线 |
  | 控件的边 | `--line-control`，悬停 `--line-control-hover` | **所有能点、能输入、而且画了边的东西**：输入框、下拉、选择器、复选、单选、开关、次要按钮、描边按钮、数量加减、标签输入 |
  | 当前 | `--action` | 选中、按下、聚焦、当前项、开着的开关 |
  | 出错、危险 | `--danger`（控件）；`--{tone}-line`（提示容器） | 出错的输入框、危险描边按钮；横幅的边 |
  | 禁用 | `--disabled-line` | 禁用的控件 |

  - 容器的边永远是 `--line`；可点的卡片悬停 → `--line-strong`；任何控件悬停 → `--line-control-hover`。
  - **控件的边和容器的边分开**：容器不需要 3:1（它不是「要认出来才能用」的东西），控件需要。按钮也是控件，所以和输入框一样深。
  - `--accent-border`、`--accent-border-strong` 不再当边框用（只剩正文引用的竖线这一种装饰）。
  - 有颜色的线只用两种：提示容器 `--{tone}-line`，控件 `--danger`（`--danger-border-strong` 在暗色下只有 2.91:1，不够 3:1）。
- **D63 宽度三种**：1px 线；1.5px 画出来的记号（转圈、图上的点、热力格当前、隔开的环）；2px 焦点轮廓和引用竖线。
- **D64 环两种**：
  - **隔开环**：1.5px `--paper`，把叠在一起或压在图上的东西切开（叠放的头像、卡片角标的点）。
  - **选中环**：隔 2px `--paper` + 环 1.5px（色块选中用 `--ink`，头像的会员环用 `--action`）。
  - 写死的 `#ffffff` 改成 `--paper`。色块自己的边仍然是 12% 的黑，因为它要压在任何颜色上都看得见；改写成令牌 `--swatch-edge`。
- **D65 门禁**：
  - 刻度测试：
    - `--r-circle` 只许名单里的选择器用；
    - 圆角不写 `50%` / `999px`；
    - 边框颜色只能是第 D62 表里的令牌（网页、小程序、展示站）；
    - 按钮的 `--btn-bd`、出错的边、聚焦的边各查一遍。
  - audit「细节」加两项：
    - 「直角模式下的圆」：名单以外，画得出来的东西圆角大于 0；
    - 「同一行控件边框不一」：一排里的按钮、输入框、下拉、选择器的边框颜色要一样。

## 5. 没改的

- **单选**永远是圆：圆 = 选一个，方 = 选几个，这是各平台通用的约定；直角模式下把单选画方，就和复选分不开了。
- **转圈、量表、庆祝的圆环、图标里的圆**：画的就是圆周运动或圆弧（图标规则本来就是「本身是圆的才画圆」）。
- **展示站画的手机外框**（`--line-strong`）：那是一张手机的图，不是界面里的容器。
- **`--accent-border`、`--accent-border-strong`、`--{tone}-border`、`--{tone}-border-strong` 这些令牌还在**：色阶的 7、8 级照样生成，只是组件不再拿它们当边框；外面的项目可能在用，删掉会坏。
- **`--focus-ring`（用了现场混色）**：组件里已经没人用（焦点是不透明的 `--focus-color` 轮廓），留着给外部项目，下一个大版本再删。
