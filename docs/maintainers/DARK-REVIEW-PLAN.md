## 0. 结论

- **整页暗色是对的**：180 页「亮着打开再切到暗」和「直接暗着打开」逐个元素比字、底、边、SVG 填充描边、阴影、画布像素，**一处都不差**（图表、量表、色块这些脚本算出来的颜色都跟着换了）。
- **坏在三个边上**：
  1. **局部暗色**（亮页面里写 `data-theme="dark"` 的一块，文档说支持）：这一块不换字色，里面没自己写颜色的字还是外面的墨色 —— 暗底上的黑字；71 页有这种。从这一块里打开、被放到页面最外层的东西（toast、确认框、命令面板、查看器、复制气泡）也回到亮色。
  2. **切主题那一下**：按钮、输入框、图标、chip（页面上 10–15% 的元素）带颜色过渡，整页已经暗了它们还亮着、慢慢变过去。
  3. **打印**：暗色页面打出来是浅灰字（打印默认不印底色，白纸上 243,240,234 的字几乎看不见）。

## 1. 怎么测的

- **切换 ↔ 直接打开**：组件、模式、模板页（中文），亮着打开后 `XxdTheme.set({ theme: "dark" })`，和暗着打开的同一页逐个元素比颜色指纹（关掉过渡，量到的是终点）。
- **局部 ↔ 整页**：亮页面里给每个演示框写 `data-theme="dark"`，和整页暗色时同一个演示框里的东西比。
- 暗色下打开对话框、sheet、面板、菜单、popover、toast、tooltip：面和页面底、边和页面底的对比度。
- 局部暗色里打开浮层，看浮层是亮是暗；暗色页面 `print` 媒体下的底色和字色；切主题后 40ms 时还在变色的元素。
- 令牌：`:root` 上用 `var()` 算出来、暗色块里没有重写的令牌（局部块里会沿用根上的值）；Kumo 只认 `<html data-mode>` 的规则。

## 3. 决定

- **D107 写了 `data-theme` 的一块是一张完整的面**：字色 `--ink`、底色 `--bg` 跟着换（`:where()`，零优先级，类名写了底色的照样用自己的）。根上用 `var()` 算的令牌（K5）在暗色块、亮色块里重写一遍。
- **D108 放到最外层的浮层跟着打开它的地方**：从锚点（或打开那一刻的焦点）往上找最近的 `data-theme`，不是根就抄到浮层上；toast 抄在每一条上（同一个区域里可能有两种）。
- **D109 切主题那一下不过渡**：`applySettings` 换主题时根上挂 `data-xxd-switching`，一帧以后拿掉；这期间所有 `transition` 关掉。只在主题真的变了时挂（换圆角、换主色照旧有过渡）。
- **D110 打印永远是亮色**：`beforeprint` 时整页和页面里暗色的块换成亮色，`afterprint` 换回来（墨水省、字看得见；和图表打印的规则一致）。
- **D111（取消）**：K7 是量错了，面板本来就有边；暗色下对话框、菜单、popover、sheet、toast、面板都有一条 1.64:1 的边，不改。
- **D112 图表盯着整页的主题**：`watchChartTheme` 也看页面里任何一块的 `data-theme` 变化。
- **D113 React 的局部暗色**：绑定层把 Kumo 只认 `[data-mode="dark"]` 的规则（代码块、日期选择、骨架屏、链接下划线）在 `[data-theme="dark"]` 里也写一份。
- **D114 门禁**：audit 加 `--only=dark`：
  - 脚本算颜色的页面（图表、量表、色块、外观、颜色页）切换 ↔ 直接打开；
  - 组件页演示框局部暗色 ↔ 整页暗色；
  - 局部暗色里打开的浮层是暗的；打印是亮的；切主题后没有还在变色的；暗色下每种浮层都有看得见的边。

## 5. 没改的

- **暗页面里的一块亮色，React 那几处**：Kumo 的代码块、日期选择、骨架屏只要祖先里有 `data-mode="dark"`（整页暗色时 `<html>` 上就有）就走暗色，里面再写 `data-theme="light"` 也拦不住。要做得用 `@scope`，先不做；HTML 组件没有这个问题。
- ~~只用 xxd.css、不加载 boot.js 的页面，系统是暗色时页面还是亮的~~：写错了（2026-10-23 TOUCH-REVIEW-PLAN 时发现）。构建出来的 tokens.css 有一段
  `@media (prefers-color-scheme: dark) { :root:not([data-theme]) … }` 的兜底，没有 JS 时也跟随系统暗色。没有 JS 时打印换亮色那一条不生效。
- **确认框、命令面板这些 JS 打开的浮层**：没有锚点，看的是打开那一刻的焦点 / 最近按下的地方；用键盘以外的方式（比如定时器里）打开的照整页的主题。
- **图片**：暗色下照片不压暗、不加边；透明底的深色 logo 在暗底上看不见，要作者自己给暗色版本。
- **`.xxd-card__rating` 的黄色、图片上的操作钮**：写死的颜色，但它们是画在图片上的，亮暗一样，不改。
