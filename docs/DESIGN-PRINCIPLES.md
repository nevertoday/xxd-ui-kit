# 小小东设计原则

> 这份文档是 xxd-ui-kit 的审美宪法。每个组件、每条 token、每个 lint 规则都要能回到这里找到依据。
> 来源（按权重）：小小东写给会员站的设计规则（2026-09-26）、会员站的 `DESIGN.md`、
> `xPoster/DESIGN.md` 和 `src/xxd-theme.css`、两个站点的 `.impeccable.md`。
> 原项目里写明的规则照搬；带「提议」标记的是本项目新补的，需要你确认。

---

## 1. 气质

- **精确、克制、实用、靠判断力。** 像出版物控制台，不像营销页，也不像玩具工具。
- **克制的编辑式粗野主义**：纸色背景、清晰的黑线、干净的无衬线字、密但好读的中文、单色调色板。
- **不要**：夸张、噱头、泛泛的 AI 未来感、霓虹暗色仪表盘、渐变卡片、超大 landing 构图、卡片套卡片、设置清单、装饰性仪表盘、超大标题、隐藏的后果。
- 为每天反复使用设计，而不是为一次性 onboarding。

## 2. 颜色

- **黑 / 白 / 灰。强调靠墨色，不靠颜色。** 颜色只留给意义（成功、危险、警告）和可选的「主色」。
- 绿色只表示「已完成 / 已应用 / 成功」。
- 暗色是**暖黑**（`#171612` / `#201f1a`），不是蓝黑或纯黑。
- **页面里的一块可以单独亮 / 暗**（`data-theme="dark"` 写在任何元素上，DARK-REVIEW-PLAN）：这一块是一张完整的面（字色、底色跟着换），
  从里面弹出来的 toast、确认框、提示也跟着它；切主题那一下不过渡（不会整页暗了按钮还亮着）；打印永远是亮色。
- **浮层抬起一层**：对话框、菜单、popover、面板、sheet、toast 用 `--paper-raised`。亮色时和纸一样（阴影托起来）；暗色时亮一档（`#292720`），因为暗底上阴影看不出来。浮层里的悬停底、分隔线跟着一起抬（`--wash-raised` 等）。
- **色阶：每种颜色同样 12 级，每一级用途固定**（借鉴 Radix Colors 的逻辑，`docs/maintainers/COLOR-SCALE-PLAN.md`）。五族：暖灰、主色、成功、危险、警告，亮暗各生成一套。组件里**不现场混色**，只用用途名：`-bg`（2 级，浅一层的底）、`-tint` / `-tint-hover` / `-tint-active`（3–5 级，淡底）、`-line`（6）、`-border`（7）、`-border-strong`（8，控件的边、聚焦，≥ 3:1）、`-solid` / `-solid-hover`（9–10，实心底）、`-text`（11，在 1–4 级上 ≥ 4.5）、`-text-strong`（12，≥ 7）、`-on-solid`（实心底上的字）。灰的用途名就是 `--bg`、`--wash`、`--line`、`--muted` 这些，值钉在灰的对应级上。门禁：`@xxd/css` 里出现 `color-mix(` 测试就失败（例外要写明原因）。
- **主色**是一个颜色定整个界面的调子：生成整套 12 级。主按钮、开关、tab 下划线、焦点用 9 级（自动模式下压暗到白字 ≥ 4.5:1，暗纸上提亮到 ≥ 3:1），链接和强调字用 11 级，选中底用 4 级；页面底、淡底、线是带一点主色的灰（OKLab 里加一点主色的方向，暖黑还是暖黑）。正文、纸、语义色不跟主色变。
- **12 个预设**，墨色是第一个也是默认；其余 10 个在 OKLCH 里明度、彩度相同，色相每隔 36° 一个（哪个都不跳出来），最后一个是低彩度的雾灰蓝。不放第三方品牌色；要用自己的品牌色就填任意颜色。
- **品牌色原样**（`accentMode: "exact"`，`<html data-accent-exact>`）：实心底（主按钮）就是原色，白字看不清时底上的字换成近黑；标记（开关、勾、下划线、当前的线）用自动模式调过的那一档，永远 ≥ 3:1（COLOR-REVIEW-PLAN D77：亮黄、白这类原色当标记在白纸上只有 1:1）；11 级（链接）照样 ≥ 4.5:1。缺省是「自动」。颜色页可以试任何颜色，看它变出的整套色阶。
- **任何主色下**（包括用户自己填的极端颜色）：标记在纸、页面底、wash、选中底上 ≥ 3:1，灰字（`--muted`）在主色的淡底和选中底上 ≥ 4.5:1（门禁拿 16 个极端颜色 × 自动 / 原样 × 亮暗验算）。
  主色和危险、成功、警告太像（`accentClash()`）时提示一句：主按钮会和危险按钮分不开。
- 文字对比度：小字至少 4.5:1（所以 muted 是 `#6d6b67` 而不是更浅的灰；放在选中底、wash-strong 上也要 4.5）。`--muted-2` 只做装饰（图标、分隔点、行号），不当文字色（占位字也不用它）。
- **有颜色的格子上的字**（热力格的数字）用配好的字色 `--heat-N-on`：中灰这种格子上白字、黑字都够不着 4.5，所以格子的颜色要避开它（D74）。
- **链接的下划线 ≥ 3:1**（`--line-control`）：墨色主题下链接和正文同色，靠这条线认出来（D79）。
- **选中 / 当前至少有一个 ≥ 3:1 的记号，不能只靠淡底**（WCAG 1.4.11，D76）：淡底和旁边只差 1.1–1.5:1，阳光下、差一点的屏幕上看不出来。
  - 导航的当前项（侧栏、列表的当前项、侧栏图标条）：左边一条 2px 的 `--action` 线，和目录一样。
  - 一组里选中的那个（分段控件、工具条按下、分页当前页）、键盘高亮的选项（命令面板、下拉、菜单）：一圈 1px 的 `--line-control`。
  - 带单选、复选的选项行照旧只是淡底：控件已经说了选了哪个。
- **意义色永远配字或符号**：绿色盲下成功和危险几乎一样（OKLab 只差 0.044），所以状态点旁边写字、变化带 + / −、横幅换图标。
- **灰都是暖灰**：亮色的底、线、控件边、次要文字和暗色一样偏暖（OKLCH 色相 80°，彩度不超过 0.008，肉眼只觉得「不冷」）。选中底和 `--wash-strong` 是同一个值，不再有两个肉眼分不出的灰。
- **开关打开是墨色**（有主色时是主色），和主按钮一致；深灰在亮纸上像禁用。
- **禁用不用半透明**：字、底、线用 `--disabled-ink / --disabled-bg / --disabled-line`。半透明叠在主色、暗色、图片上颜色没法预测，设计稿也没法标。禁用的字不要求 4.5:1，但要和能用的一眼分开。
- 系统要求更高对比度（`prefers-contrast: more`）时，控件边框加深到 3:1、次要文字到 6:1；Windows 高对比模式（`forced-colors`）下，选中、勾选、进度都用系统色重画，选中态有不靠颜色深浅的描边。平时保持安静的发丝线。

## 3. 圆角：直角 / 圆角两态

- **默认直角。** 会员站是硬规则：对话框、卡片、按钮、输入框、图标背景都不许圆角（`border-radius: 0`）。
- 插件里可以在「外观」设置里切成圆角：`<html data-corners="rounded">`。
- 圆角刻度只有五档：`--r-xs` 4px（小标记）、`--r-sm` 6px（控件）、`--r-md` 10px（面）、`--r-lg` 14px（大面）、`--r-pill`（状态标签、开关，以及正方形的头像、点、色块）。
- **直角模式下开关也是方的。**
- **只有「形状就是意思」的才永远是圆**（SHAPE-LINE-PLAN D61）：单选（圆 = 选一个，方 = 选几个）、转圈、圆弧和图标里画的圆。只有单选和转圈用 `--r-circle`。
- 头像、色块、状态点、徽标的点、图上的点都**跟开关走**（`--r-pill`）：直角时是方的，圆角时是圆的。小而可爱不是画圆的理由。
- 所有矩形圆角都只能通过这五个 token 取值，不许写死数字。
- 是否允许某个产品**锁死**直角（会员站）或锁死圆角，由产品决定，组件库只提供开关。

## 4. 线

线是有意图的。空间先分隔；只有空间做不到时才画线。

- 线只出现在：列表行之间、tab 的基线、dock 的上沿、控件自己的边框、容器的边。
- **永远不出现两条中间什么都没有的线**：tab 下面不再画标题线；主 tab 下面不再紧跟一条全宽线。
- sheet 里的分组靠间距和小标题分，不靠上下两条横线；列表只在行**之间**画细线，第一行上面、最后一行下面都不画。
- 一组选项是一个列表，不是一叠盒子；一格符号是裸字符，hover 时才填色，按下的那一个多一圈控件边（D76）。
- **一个框只有一个框**：输入框聚焦时边框变深一次就够（外面不加光圈，里面不加内框）。外扩的焦点环（2px、隔开几像素）只给按钮、链接这类点一下的东西；能打字的框（输入框、搜索框、多行框、下拉框）不套，否则就是「黑框套灰框」，还比同一行的按钮高出一截（2026-10-19，会员站管理员工作区）。容器级的 `:focus-visible` 规则要排除这些框；分段控件是一个托盘，选中的那段像纸一样浮出来，不是框里套框；选中行是一层淡色（radio 已经说明选了哪个），不是淡色 + 彩色边 + 竖条；没有 radio 的导航当前项才用左边那条线（§2）。
- 浮层保留一条安静的边（`--line`），因为阴影已经把它托起来了。
- **线的颜色只看用途**（SHAPE-LINE-PLAN D62）：

  | 用途 | 令牌 |
  |---|---|
  | 分隔、容器（卡片、分组、横幅、浮层） | `--line`（浮层里自动是 `--line-raised`） |
  | 结构线（表头下、合计上、键帽、拖放区） | `--line-strong`；可点的卡片悬停也是它 |
  | 控件的边（输入框、下拉、选择器、复选、单选、开关、次要和描边按钮） | `--line-control`（≥ 3:1），悬停 `--line-control-hover` |
  | 当前（选中、按下、聚焦、当前项） | `--action`；实心的东西边和底同色 |
  | 出错、危险的控件 | `--danger`；提示条的边 `--{tone}-line` |
  | 禁用 | `--disabled-line` |

  容器不需要 3:1，控件需要。按钮也是控件，所以和输入框边一样深，同一行不会一深一浅。
- **宽度三种**：线 1px；画出来的记号（转圈、图上的点、热力格当前、隔开的环）1.5px；焦点轮廓和引用竖线 2px。
- **环两种**：隔开环 1.5px 纸色（叠放的头像、压在图上的点）；选中环隔 2px 纸色 + 1.5px 墨色或主色（色块选中、头像的会员环）。不写死白色。

## 5. 阴影与层次

- 卡片、行、按钮**没有阴影**。实心按钮可以开「质感」（`data-finish="material"`）：顶部 1px 内高光 + 深一点的边 + 按下下沉 0.5px ——
  这是材质，不是浮起；是否默认开启在展示站并排比较后决定（D1）。
- 只有浮层有阴影：tooltip、菜单、toast、对话框、dock sheet（`--shadow-popover` / `--shadow-dialog`）。
- 设置组 = 一个灰色小标题 + 一个带框的主体，里面的行用细线分开。整个 tab 外面不画框。
- 下拉选择是「一个值 + 一个 chevron」，不是一个盒子。
- tab 是基线上的文字，当前项下面一条短墨线滑过去。

## 6. 字体

- 只用系统里已有的**无衬线**字体，不用宋体 / 衬线，不加载网络字体。标题 `--font-title` 和正文 `--font-body` 是同一家族，层级只靠字号和字重。
- 先英文字体再中文字体：英文是 Avenir Next（macOS）/ Segoe UI（Windows），中文是苹方 / 微软雅黑 / 思源黑体。繁体页面（`lang="zh-Hant"`）换成苹方 TC / 微软正黑体。
- **字重只用 400 / 500 / 600。** 浏览器给 `<b>`、`<strong>`、`<th>` 的 700 统一收到 600。
- **600 只给「整屏的标题」和大数字**（TYPE-REVIEW-PLAN D67）：页面标题、节标题、对话框标题、统计和量表的数字。块里的标题（卡片、面板、横幅、图表卡、popover、空状态）是 500。
- **层级五级，相邻两级至少差一档字号**：页面标题 28 / 600 → 节标题 20 / 600 → 小节、块的标题 16 / 500 → 正文 13–14 → 说明 12（灰）。展示站和组件用同一套档（D66）。
- **不用斜体**（D70）：中文没有真斜体，浏览器会把字硬拉斜。强调用字重或颜色；代码注释只靠灰色。
- 选中状态用颜色和底色表示，**不加粗**（加粗会让布局跳）。
- **相关的字靠得更近**：标题和它的说明之间的距离，要小于这一组和下一组之间的距离。
- 文字周围的垂直间距略小于水平间距（光学对齐）；不改字距。
- **换行要像排过版**：最后一行不只剩一个字；标题几行长短均匀；数字和单位、短链接、代码名不拆开；按钮、标签、tab 的字永远一行、不贴边。
  放不下时让按钮整体换到下一行、让表格横向滚动，而不是把字挤窄。（门禁：`pnpm --filter @xxd/site run audit` 的「细节」一项）
- **放不下的字：内容折行，标签才省略**（TRUNCATION-REVIEW-PLAN D91–D95）：
  - **内容永不截断**：标题（卡片、面板、列表行、对话框）、状态（dock 状态、toast、出错）、数字（统计值、价格、合计）、图表的类别名。放不下就折行，旁边的按钮、数字换到下一行；
  - **标签一行**：按钮、chip、徽标、tab、面包屑、侧栏项、下拉的当前值。放不下才在**末尾**出省略号，不两边裁、不从字中间切；
  - **被省略的都能看到全文**：悬停、键盘聚焦时提示全文；
  - **截断的数字是错的数字**：放不下先缩写；对话框的主操作放不下就整个换到下一行，不把自己的字挤成省略号。
  - （门禁：audit 的 `--only=trunc`）
- **字号阶梯**：11 · 12 · 13 · 14 · 16 · 20 · 24 · 28，相邻两档至少差 1px 且各有用途（15px 那一档去掉了）。
- **字号和行高成对**，行高都落在 4px 网格上：11 / 16、12 / 16（一行的标签）、12 / 20（说明文字，会折行）、13 / 20、14 / 20、14 / 24（说明页的段落）、16 / 24（标题）、16 / 28（阅读正文）、20 / 28、24 / 32、28 / 36。固定高度的单行控件行高写 1，由控件高度居中；不写 `normal`。
- 说明文字（字段提示、设置行的说明、空状态、对话框的补充）统一 12px / 20。
- 行内等宽字比周围**小一档，落在阶梯上**（D69）：13 → 12、14 → 13、16 → 14、20 → 16、24 → 20、28 → 24，但不小于 12（里面可能有中文；`max(var(--text-xs), calc(1em - clamp(1px, 1em - 14px, 4px)))`）；图标与多行文字的第一行对齐。
- 导航 13px / 500；菜单 12px / 500；侧栏图标下的标签、tooltip、徽标 12px。
- **中文不小于 12px**（D71）：Windows 1 倍屏上 11px 的雅黑发糊，一些中文环境的浏览器会把最小字号设成 12px。11px 只给不会出现中文的：键帽和快捷键、等宽的名字（类名、文件名）、图上的刻度数字、小程序的底部标签栏。
- **间距**只用 4px 刻度（`--space-1` 到 `--space-8`）；两个半档只给光学上的小间隔：2px（托盘内缩、标签和角标）、6px（图标和字之间）。和图标对齐的缩进写成「图标尺寸 + 间距」，不写算好的数字。
- **间距按用途选，不按感觉选**（SPACING-REVIEW-PLAN D54–D56）：
  - 组件写用途令牌。容器内边距只看「这是什么容器」，不看它多宽：`--inset-sm` 12（卡片、格子）、`--inset-md` 16（一块内容）、`--inset-lg` 20（对话框、右侧面板）。
  - 间隔按关系分四档：部件 `--gap-tight` 4 < 同类 `--gap-items` 8 < 块 `--gap-block` 16 < 组 `--gap-group` 32。
  - 紧凑密度下，容器和块、组之间都小一档。
- **看起来四边一样**（D55）：容器以文字开头时，上下内边距比左右小一档（`--inset-*-y`），行高的半行距正好补上。只有图、按钮贴边时四边写一样。
- **对齐只有两条线**（D57–D59）：
  - **外线**是框、分隔线、整行宽的控件的边，框外面的字贴它。**内线** = 外线 + 内边距，框里面的字贴它。不许「差 1–3px」。
  - 二级缩进（列表、引用）只有一种：`--space-5`。
  - 角上的幽灵图标按钮按图标对齐，往外让出（按钮 − 图标）/ 2。
  - 比一行矮的东西（图标、关闭）对齐第一行的中线；比一行高的（按钮）上沿对齐第一行。
- 阅读列宽 680px（或 70ch）；工具条、dock 可以全宽，被阅读的东西居中成一列。

## 7. 图标

- 一个家族：24 单位网格，`stroke-width` 1.5，圆头（round caps），**斜接角（miter joins）**，不填充。
- **直线和方角**，坐标落在半像素上（3.5, 20.5）；**不要** Lucide 的圆角矩形和转角弧线。只有东西本身是圆的才画圆（时钟、播放、放大镜）。
- 尺寸：12px（小字旁的 chevron）、14px（与文字同行）、16px（按钮和控件内）、18px（工具栏）、20px（侧栏）。更大只用于插画。
- 激活态改颜色/填充，**永远不改线宽**。
- 品牌标志、用户作品、头像、图表 SVG 保留自己的画法。

## 7½. 同心圆角

- 两层边框 / 底色相距 8px 以内时，圆角要同心：**外圆角 = 内圆角 + 间距**（`.xxd-concentric`）。直角模式下自然都是 0。

## 8. 动效

- 动效用来揭示层级和给反馈，不是装饰。像一次有引导的走查：细微、有目的、快、有触感。
- **只动 opacity 和 transform。不弹跳、不弹性、不霓虹、不粒子。**
- 五档速度：quick 140ms（状态变化）、panel 180ms（右侧面板滑入）、sheet 200ms 升起 / 120ms 收回（ease-out-expo）、medium 220ms（小型进入）。
- **hover：进入立即变，离开 140ms 淡回**（2026-10-12 决定 D2）。快的交互带过渡会显得迟钝。
- **按下也是立即变**（MOTION-REVIEW-PLAN D82、D83）：每个能点的东西按下的同一刻就要有看得见的变化，松开 140ms 淡回。
  - 没有自己按下样式的透明底控件，按下统一深一档（`--wash-strong`）；
  - 开关、复选、单选、分段、tab 按下后状态立刻变，不另加。
  - 手机上没有悬停，点下去要马上知道点到了。
- **进行中晚 150ms 才露出来**（D85）：`aria-busy` 立刻生效（防连点），很快的操作字不会闪一下。
  完成后有图标的换成勾，没图标的字透明、中间一个勾，1 秒后恢复（D86）。
- **toast 的时长按内容算**（D87）：
  - 只是告知：2.6 秒起，每个字加 0.1 秒，最多 8 秒；出错至少 6 秒；带操作（撤销）10 秒；
  - 悬停、聚焦、页面在后台时都暂停。
- **菜单、popover、tooltip、下拉列表从锚点方向长出来**：0.96 → 1 + 淡入 140ms，收回 100ms（`--motion-out`）；对话框和 sheet 保持升起（D4）。
  tooltip 关掉后 300ms 内移到下一个按钮，立即出现、原地换字。
- 折叠展开只淡入 + 小位移，不做高度动画（D3）。
- 进行中的按钮宽度不跳：文字保留但透明，转圈居中；完成后图标变勾 1 秒。
- sheet 从 dock 升起 10px 并淡入；切 tab 是原地短淡入（东西不移动，部件不逐个进场）。
- 减少动效：一次性全部静止；内容始终可见。只有表示「正在进行」的转圈、加载条（包括按钮里的）换成很慢的淡入淡出：不转、不跑，但也不定住，定住像卡死了。

## 9. 交互结构

- **状态优先级**（ACCEPTANCE-REVIEW）：禁用 > 进行中 > 出错 > 选中 / 当前 > 键盘焦点 > 按下 > 悬停 > 默认。两个状态同时成立时，高的那个说了算：
  - 禁用、进行中的东西悬停和按下都不变；
  - 选中 / 当前的东西悬停时选中的记号不变；
  - 出错又聚焦：边还是出错色，加粗成 2px（两样都看得见）。
- **出错**（FORM-REVIEW-PLAN D97–D104）：
  - 错误写在整个控件下面（不进框、不进 label；设置行里写在左边那一栏），前面一个危险图标，不只靠颜色；出错时错误顶替说明；
  - 文字说清楚怎么改：「至少 8 位，还差 3 位」「请输入有效的邮箱，比如 you@example.com」，不写「输入有误」；
  - 提交时才报错，焦点到第一个错；改对了马上清掉，打字时不催；
  - 用输入法拼字时按的回车、Esc 只给输入法；邮箱、网址里的全角字符先换成半角，不算用户写错。
- **能打字的框聚焦时边变成 2px**（`--action` 的边 + 里面贴 1px）：还是一个框，不往外加光圈。1px 的变化在暗色主色下只差 1.4:1。
- **焦点环不能被裁**：横向滚动的 tab、带省略号的面包屑、代码块里的焦点环画在元素里面（`outline-offset: -2px`）。
- **嵌套的层**：
  - 面板 / sheet 上再开模态对话框，键盘和 Esc 归对话框；
  - 面板里的下拉、拖动排序先拿到 Esc，不会一下关掉整层；
  - 打开浮层的东西不在了（那一行被删了），关掉后焦点回到下面一层，不掉到 body。
- **不可恢复的操作要能回头**：
  - 覆盖设置（导入）给「撤销」；两次确认双击不算、Esc 退回；
  - 拖动排序 Esc 放回原样，并且有不用拖的「上移 / 下移」（WCAG 2.5.7）；
  - 可点的整行用 `<button>` / `<a>` 写，键盘到得了。

- **任务优先。** 每个设计选择都要强化清晰、信任和行动。
- 状态可见但不吵：进度、警告、限额、页面就绪都要清楚。
- 偏好可撤销的操作和清晰的恢复路径。
- **反馈就地出现**：在右侧面板里做的操作，toast 出现在面板里，不盖住主内容区。
- **底部 dock 是紧凑的任务控制台**，不是第二条导航：上下文和实时状态在开头，可撤销的选择工具成一组，后果最大的下一步在末尾。破坏性操作单独放、写清楚，不能只靠图标或颜色。
- **按钮文字描述下一次点击会做什么。** 切换按钮带 `aria-pressed`。
- 忙碌状态由一个 render 函数从应用状态反映；请求中禁用冲突控件；部分失败保留可重试的选择。
- 每个设置 URL 自己就是完整任务面，不需要第二次点击才能看到主要控件。

## 10. 对话框的按钮层级

- 取消、关闭、返回、「稍后」是**辅助操作**：用 `ui-dialog-cancel`，内容宽度、视觉安静：不 flex-grow、不等宽、不撑满整行、不用实心主色/危险色。
- 取消在 DOM/tab 顺序上**放在主操作前面**，让主操作成为最后/最右的那个承诺。窄屏上主操作可以占剩余宽度、可以换行，但取消始终是内容宽度。
- 最小点击区 40px（粗指针 44px），焦点可见。
- 标题栏的纯图标关闭按钮是另一种紧凑模式，不用 `ui-dialog-cancel`。
- **按行为分类，不按文字分类**：如果复用的按钮从「关闭」变成真正的另一个操作，就去掉 `ui-dialog-cancel`，换成次要操作样式。

## 11. 文案

- 直接、实用、照字面、让人安心。动作用动词；元数据只写事实。
- 设置项说明会影响谁、是否自动保存。
- 产品名用四个朴素的字说清它做什么（如「长文发布」「批量存图」「今日待办」）。
- 简体 / 繁体 / 英文三语；英文不回落到中文内容。

## 12. 无障碍与响应式

- 目标 WCAG 2.1 AA：原生 button/link、可见焦点、键盘可切换、明确的排序控件、命名的区域、save 状态用 live region。
- 没有任何交互依赖动效、hover 或拖拽。
- 侧边面板在手机上变成全宽 sheet；设置在手机上单列。
- **断点只有三个**：480（手机）、640（窄屏：对话框和右侧面板变成底部抽屉）、1024（桌面：侧栏和目录同时出现）。出稿也按这三个宽度出（另加 1280 看桌面的宽松版）。
- **同一行的东西一样高、在一条线上**：并排的按钮、输入框、chip 用同一档高度；表格同一行各格的字在一条基线上。
- 主题、圆角、主色在**首帧之前**生效（不闪）。
- **手指**（粗指针，TOUCH-REVIEW-PLAN D115–D121）：
  - 控件 44 高（和小程序一样），每个能点的东西点按区至少 44；挨着排的一组（按钮组、分段、色块）每个至少 24，文字链接、文字按钮至少 24；
  - 能打字的框字号 16px（iOS 小于 16 一聚焦就放大整页）；
  - 悬停只给能悬停的指针（手指点过，悬停的样子不留在那儿）；手指点按不弹提示；
  - 浮层里滚到头不接着滚后面的页面；贴底的东西让出 iPhone 的安全区。

## 13. 小程序和手机

小程序版（`@xxd/mini`）的气质和上面完全一样：直角、墨色、暖黑、发丝线、系统字体，卡片和按钮不加阴影。这一节只补手机上的交互规则，不改样子（手机上常见的大圆角卡片、渐变按钮、彩色图标都不要）。

- **点得到**：能点的东西至少 44 × 44px（`--hit-min`；网页控件 40px，手机上大一档）。
- **避开胶囊按钮**：自定义导航栏按 `getMenuButtonBoundingClientRect()` 给右上角的胶囊让位，标题和胶囊垂直居中对齐（`NavBar` 已经做好）。
- **底部安全区**：底部的按钮条、标签栏、底部面板加上 `env(safe-area-inset-bottom)`。
- **鼠标交互换成手机交互**：菜单、浮动卡片换成底部面板；不做悬停提示，说明直接写在界面上；右键换成长按。
- **按下要有反馈**：按下时给一层淡色（`hover-class`），不加粗、不放大。
- **返回键先关浮层**：底部面板、对话框打开时，手机的返回键或右滑先关浮层，不直接离开这一页。
- **尺寸用 px**：和网页版是同一组数字，不按屏幕宽度换成 rpx；1px 的线不发虚。
- **跟随系统亮暗**：小程序缺省跟随系统；用户在设置里选了亮或暗，以用户的为准。
- **整行可点**：带开关、复选框的列表行，点整行就是切换；读屏上整行是一个开关。
- **底部空间一起算**：标签栏（`--tabbar-h`）、底部按钮条（`--bottombar-h`）、安全区加起来是 `--bottom-inset`，页面底部、轻提示、浮动的东西都按它留位置。主操作放底部按钮条，少用浮动按钮。
- **标签栏用自带的**：`tabBar.custom` + `TabBarHost`，切页不销毁页面。
- **跟手的动作**：底部面板按住把手往下拖就关（不能关的不画把手）；长按生效时轻震一下。
- **手机上的字不小于 12px**：只有标签栏的字和角标数字是 11px（`--text-tab`），和系统自带的标签栏一样。
- **一行的高度**：一行字的列表行 52px（`--hit-min` + 8），带开关、带值、带复选框都一样高。

## 14. 数据可视化

图表、统计卡、计量条、量表（`docs/maintainers/GAUGE-PLAN.md`）、条形榜、构成条、百格图、热力格、前后对比（`docs/maintainers/CHART-TYPES-PLAN.md`）共用这几条。

- **按数据形状选图**（`docs/maintainers/CHART-TYPES-PLAN.md`）。不拿一排量表凑一张图，不做装饰性仪表盘、网络图、放射图、入场动画（§1、§8）：

  | 数据形状 | 用什么 |
  | --- | --- |
  | 趋势（随时间变化） | 折线（`Chart`）；统计卡里用迷你折线，每天一个数用迷你柱 |
  | 少类目比较、排名（≤ 12） | 条形榜 `Bars`；能数的少量数字按单位切格 |
  | 有正有负 | 条形榜的正负条 |
  | 分阶段递减（转化） | 条形榜的漏斗 |
  | 一个总数拆成增减（毛收入 → 净收入） | 条形榜的瀑布 |
  | 今年 vs 去年（每类两个数） | 条形榜的对照值（细灰条）；只看变化用前后对比 |
  | 分箱频数（直方图） | 条形榜、不排序，名字写区间（「0–1 小时」） |
  | 偏差、盈亏（有正有负的一个数） | 量表的 `origin`（从 0 往两边长） |
  | 一个整体分成几部分（≤ 5） | 构成条 `Proportion`；只有几个百分比时用百格图 `Waffle`（不用饼图） |
  | 两个时点的前后对比（≤ 8 类） | 前后对比 `Dumbbell` |
  | 全年每天一个数、星期 × 时段 | 热力格 `Heatmap`（日历 / 矩阵） |
  | 一个数和上期比 | 统计卡 `Stat` |
  | 一个数在范围里的哪儿 | 计量条、量表 `Gauge` |
- **图的家具要有，但只放有用的**：参考线（平均、目标）是墨色实线；刻度数取整到 1 / 2 / 5 × 10ⁿ，网格是发丝线；旁注写在数字下面。没有数据时写「没有数据」，不留一块空白。
- **单位可数、写出来**：条从 0 开始、不断轴；百格图 1 格 = 1%，取整用最大余数法（加起来正好 100）；单位、口径、来源写在图下的说明行（`.xxd-chart-card__note`），标题写结论。
- **颜色还是只表意义**：重点那一条（一个量表的填充、第一条线、标了重点的那根条）是主色，没设主色就是墨色；其余是灰阶的深浅。顺序（热力）用 `--heat-1…4`，越深越多；正负都是墨色，涨跌不等于好坏。成功 / 危险 / 警告只在数据真的达标、超限时出现，并且旁边写出状态，不只靠颜色（WCAG 1.4.1）。分类色固定五种，顺序是主色 9、灰 9、主色 8、灰 10、灰 11：和纸色都 ≥ 3:1，深浅交替，相邻两类分得开；超过五类时前四类加「其他」，不悄悄丢。地方小的数字（量表中间、矩阵格子、刻度）写全了太长就缩写，截断的数字是错的数字。
- **线还是有意图的**：网格线是发丝线（`--line`），刻度、目标线、指针是 1–1.5px 的像素线；没有渐变、阴影、3D、发光。粗线（量表的轨道和填充）的线头跟圆角模式（`--stroke-cap`），格和格之间的缝永远是平的。
- **字是 HTML 字**：数字、单位、刻度数、图例用系统字体和等宽数字（tabular-nums），不画进图里；刻度数少而准（量表只标两端）。
- **动效还是只动 opacity / transform**：不做进场动画；值变了指针转过去（`--motion-medium`），填充直接到位。
- **读屏读得到结论**：一个数用 `role=meter` 加整句的 `aria-valuetext`；图表旁边有一句话结论或一张表；图本身 `aria-hidden`。

## 提议（本项目新增，待确认）

- **P1 密度两档**：`data-density="compact"` 给 Chrome 侧边栏/popup 用（控件 32px），缺省 40px 给网站。来源：xPoster 实际以 12–13px、紧凑行为主，会员站以 40px 控件为主。
- **P2 Shadow DOM 注入**：插件往第三方网页（如 X）注入的 UI 一律放进 Shadow DOM，令牌同时提供 `:host` 版本，避免和宿主页面样式互相污染。
- **P3 规则可执行**：上面能机器检查的规则（圆角只走 token、卡片无阴影、字重三档、图标线宽与 miter、对话框按钮顺序、主色对比度）都做成 lint 或测试，像会员站的 `*-contract.test.mjs` 一样当门禁。
