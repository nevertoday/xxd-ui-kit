图型对抗测试（docs/maintainers/CHART-REVIEW-PLAN.md）：

- 超过 5 类时并成「其他」，合计按全部算（以前悄悄丢掉）；占比 0 的段不画，不是 0 但取整成 0 的写「<1%」。
- 窄（< 360px）时条形榜、前后对比的名字单独一行，旁注换到条下面；以前有旁注时 320 宽条被挤到 0。
- 按单位切格时，对照条和参考线不再被遮罩裁掉（条多了一层 `.xxd-bars__bar`）；正负条的对照值从中线画；瀑布落到 0 以下有 0 线。
- 热力格每一格的数：指到或点到时写在色阶那一行（`.xxd-heatmap__readout`），手机和小程序也看得到；`title` 换成 `data-tip`。
- 日历缺省到本地的今天（以前是 UTC）；在隐藏的容器里画也停在最近一周；矩阵的行名横着滚时固定、缺数据和 0 分开。
- 量表中间、矩阵格子、刻度的大数自动缩写（截断的数字是错的数字）；负数一律用真减号。
- 分类色顺序改成主色、灰 9、主色 8、灰 10、灰 11：深浅交替，相邻两类分得开。
- 高对比模式下矩阵的数看得见、热力五档各不一样；打印时印出背景色。
- 声明式写法：数里的千分位能读，坏的一项在控制台提示。
