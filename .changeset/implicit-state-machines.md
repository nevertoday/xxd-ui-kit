隐式状态机的修正（定时器不清、共用的东西没有归属、只写了正常路径的结束）：带操作的 toast 不再合并，连删两条各撤各的；toast 计时要鼠标、焦点、页面在后台都放开了才重新开始；鼠标从一个按钮移到相邻按钮，提示不再 120ms 后消失；复制按钮、`runBusy` 1 秒内再来一次不会卡在勾上；触屏长按途中滚动（pointercancel）或手指移动不再进入拖动；一个 sheet-host 里几张 sheet 共用遮罩，关一张不再把遮罩和 `inert` 全撤掉，点遮罩关最上面那张（React `Sheet` 同样按归属计数，开着时卸载也把焦点还回去）；uninstall 再 install 后 tab 下划线、tab 溢出、表格边缘、热力格读数重新挂上，单独调 `init()` 建的观察者归到所在的 install 上。`XxdAppearanceProvider` 只存用户选过的几项（不再把 initial 存进共享设置），换 storageKey 不带旧值，跟着别的标签页变。插件外观存储：自己写入的回声晚到不再把刚改的一项短暂改回去，写入前合并最新的存储（另一页刚改的那项不被冲掉，内容脚本 load 之前 set 不清掉其余几项），写入失败时界面回到存储里的样子。插件模板的账号只有一个状态（signed-out → signed-in → member），会员存下来，退出清掉，别的窗口跟着变，双击「我已支付」只开通一次。小程序输入框到上限后再打字，多出来的字会从原生输入框里写回去。展示站检查脚本 `--only=` 拼错时报错退出，不再显示全部通过。
